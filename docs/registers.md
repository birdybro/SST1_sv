# Registers

SST-1 register map as implemented in this project.

This document is filled in during **Phase 2**. It will contain:

- Address offsets for the memory-mapped register region.
- Reset values.
- Bit-field layouts for control registers (fbzMode, fbzColorPath,
  alphaMode, fogMode, textureMode, etc.).
- Notes on registers that are stubbed vs. fully implemented.

Authoritative source: SST-1 spec Rev 1.61 (see `docs/references.md`).
